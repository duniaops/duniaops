# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities through a public GitHub issue.

Email [info@duniaops.com](mailto:info@duniaops.com) with the subject
`[SECURITY] DuniaOps website`. Include the affected URL or component, the
steps needed to reproduce the issue, its likely impact, and any suggested
mitigation. Do not include credentials, personal data, or destructive proof of
concepts unless we have agreed on a secure way to receive them.

We aim to acknowledge a report within five business days. We will coordinate
validation, remediation, and disclosure with the reporter where appropriate.

## Supported version

Security fixes are applied to the version currently deployed at
[www.duniaops.com](https://www.duniaops.com). Historical commits and older
deploys are not supported.

## Scope

This policy covers the DuniaOps website and its build/deployment configuration.
Reports about third-party services should be sent to the relevant provider
unless the issue is caused by DuniaOps configuration or integration code.
